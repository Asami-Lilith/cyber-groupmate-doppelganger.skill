# 提示词程度五档（权重→措辞）

> 在 MUST/SHOULD/MAY 三档上加两档，使 0.45/0.25/0.30 的转换更平滑

| 档位 | 权重区间 | 关键词 | 行为 | 注入量 |
|------|----------|--------|------|--------|
| L5 MUST 必须 | 0.4-1.0 | 必须、不得、仅 | 硬约束，不可违背 | Top10 + 3条 verbatim，放末端 |
| L4 SHOULD 应该 | 0.25-0.4 | 应该、优先、强烈建议 | 强推荐，冲突时优先 | Top5 + 1条示例 |
| L3 RECOMMENDED 建议 | 0.15-0.25 | 建议、可考虑 | 推荐，可权衡 | Top3 |
| L2 MAY 可 | 0.05-0.15 | 可、适时、可选 | 可选，合适时触发 | 1-2条规则 |
| L1 OPTIONAL 仅参考 | 0-0.05 | 仅作参考、兜底 | 低优，仅无其他时参考 | 1句兜底 |

## 本项目映射（五档版）
- 近期热点 hot (0.30) → L5 MUST："必须优先模仿近期Top10，冲突时以此为准"
- 近期常用 common (0.15) → L4 SHOULD："应该贴近近期常用词"
- 底座 base (0.30) → L3 RECOMMENDED："建议参考底座性格"
- 表情包 emoji (0.25) → L2 MAY："可适时调用 send_sticker"
- 兜底 fallback (0.0) → L1 OPTIONAL
